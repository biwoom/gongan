# 디자인

[디자인 방향](../docs/design-direction.md)을 기준으로 화면 흐름, 시각 콘티와 검토 결과를 둡니다. 첫 예정 산출물은 iPhone 기준 정원 입구·꾸띠 문·차와 휴식의 3장 콘티입니다. 사용자가 승인한 내부 컨셉 표준은 원본 JPEG 4장입니다. [표준 목록](../docs/design-direction.md#확정-컨셉-표준--사용자-첨부-원본-4장)을 참고하세요. 원본 폴더 `reference-originals/`는 Git에서 제외합니다. 표준 채택과 별도로 시각 콘티 v01·v02는 승인되지 않았습니다.
