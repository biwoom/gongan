# 공간 (gongan)

**웹이라는 공간을 활용해 불교적 게임, 휴식, 명상 경험을 나누는 체험소**

공간은 설명을 먼저 읽는 서비스보다, 편안히 머물고 필요할 때 더 깊이 탐색하는 경험을 지향합니다. 기존 ‘온라인산사’ 논의는 기획 배경이며 현재 프로젝트 이름은 **공간**입니다.

## 현재 상태

기획 문서와 기본 폴더만 준비한 단계입니다. 실행 가능한 웹 경험, 서버, 계정, 앱, 배포는 아직 없습니다. 기술 스택과 일정은 제안이며 확정된 구현 결과가 아닙니다.

첫 진입점은 **나만의 힐링스테이**입니다. 개인 정원에서 한국 사찰풍 꾸띠로 들어가 차를 곁에 두고 머무는 흐름을 검토합니다. 설명·교학·대화·차 마시기를 의무로 두지 않습니다.

## 다음 산출물

iPhone 기준 **정원 입구 → 꾸띠 문 → 차와 휴식**의 시각 콘티 3장을 먼저 검토합니다. 승인 뒤 작은 정적 웹 시제품으로 확인합니다. 실제 이용자나 계정 없이 시험하며, 성공하면 별도 법당과 NPC 한 명으로 확장하는 안입니다.

## 경계

참고 서비스 [SANSA](https://sansatemple.com/), Journey, Monument Valley는 경험·공간 연출의 참고점일 뿐입니다. 코드·이미지·음원·캐릭터를 복제하지 않습니다. 홈페이지 연동, Pages 설정과 배포, 외부 공개 및 유료 서비스는 해당 범위의 별도 승인 없이 진행하지 않습니다.
